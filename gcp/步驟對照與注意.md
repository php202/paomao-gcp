## 二、重要：服務帳戶要一致

- **試算表**你共用給：`paomao-967@gen-lang-client-0828139766.iam.gserviceaccount.com`
- **Cloud Run Job 預設**是用「專案預設 Compute 服務帳戶」跑：  
  `專案編號-compute@developer.gserviceaccount.com`

若 Job 用預設 Compute 帳戶跑，但試算表只共用給 paomao-967，Job 會**讀不到試算表**。

**請二選一：**

1. **改試算表共用**：把「員工清單、店家、Token、產出」也共用給  
   `專案編號-compute@developer.gserviceaccount.com`（編輯者），  
   查專案編號：`gcloud projects describe gen-lang-client-0828139766 --format='value(projectNumber)'`
2. **改 Job 用 paomao-967 跑**：建立 Job 時加  
   `--service-account=paomao-967@gen-lang-client-0828139766.iam.gserviceaccount.com`  
   並且 **Secret Manager 的 saydou-token、gmail-user、gmail-app-password 都要授權給 paomao-967**（不是只授權給 default compute）。

執行指南裡是用「預設 Compute 帳戶」做 Secret 授權與 Scheduler，若你選 (2)，腳本也要改成用 paomao-967。

## 三、saydou-token 補齊步驟

1. 從表單取得 SayDou Bearer Token。
2. 若 Secret 已建立但沒值，可加新版本：
   ```bash
   echo -n "從表單複製的Token" | gcloud secrets versions add saydou-token --data-file=-
   ```
3. 讓「跑 Job 的那個服務帳戶」能讀 saydou-token：
   ```bash
   source set-env.sh
   export PROJECT_NUMBER=$(gcloud projects describe $PROJECT_ID --format='value(projectNumber)')
   # 若 Job 用「預設 Compute」跑：
   gcloud secrets add-iam-policy-binding saydou-token \
     --member="serviceAccount:${PROJECT_NUMBER}-compute@developer.gserviceaccount.com" \
     --role="roles/secretmanager.secretAccessor"
   # 若 Job 用 paomao-967 跑，改成：
   # gcloud secrets add-iam-policy-binding saydou-token \
   #   --member="serviceAccount:paomao-967@gen-lang-client-0828139766.iam.gserviceaccount.com" \
   #   --role="roles/secretmanager.secretAccessor"
   ```

## 四、接著照執行指南：建立 Job + Scheduler

執行指南「三、依序執行」裡的 **4. 建立兩個 Cloud Run Job** 和 **5. 給 Scheduler 權限**、**6. 建立 Cloud Scheduler** 可以：

- **手動**：在 `gcp` 目錄下，把 執行指南 的指令一段段複製到終端機執行（注意貼上時不要有前後空白導致整行被當成一個指令）。
- **或用腳本**：已幫你寫好 `setup-jobs-and-scheduler.sh`，會依執行指南建立 Job 與 Scheduler。  
  執行前請先：
  1. `source set-env.sh`
  2. 在 `set-env.sh` 或本機 export 設定好四個試算表 ID：  
     `LINE_STAFF_SS_ID`、`LINE_STORE_SS_ID`、`OUTPUT_SS_ID`、`TOKEN_SHEET_SS_ID`  
     （執行指南裡有範例 ID，請改成你的實際 ID）

執行指南裡 Job 2 的 `--set-env-vars` 有試算表 ID，務必改成你的實際值，否則月報會連錯試算表。
