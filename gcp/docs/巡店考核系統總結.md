## 📊 **核心功能**

### **1. 智能提醒系統**
```
每日9點自動檢查 → 3天內到期提醒 → 逾期升級警報
```

**儀表板頂部提醒區：**
```
🔔 本週需要巡店的門市：
┌─ ⚠️ 新竹公道店 - 已逾期2天 [立即巡店]
├─ ⚠️ 桃園南崁店 - 3天內到期 [安排巡店]  
└─ ⚠️ 楊梅金山店 - 明天到期 [安排巡店]
```

### **2. 專業評分標準**
基於美容業專業督導角度設計：

| 分類 | 關鍵扣分項目 | 扣分 | 理由 |
|------|------------|------|------|
| **衛生管理** | 潔面刷發霉 | -15分 | 直接接觸臉部，感染風險極高 |
| **法規遵循** | 滅火器缺失 | -20分 | 消防安全重大風險 |
| **設備維護** | 殺菌箱鏽蝕 | -10分 | 影響殺菌效果 |
| **員工規範** | 未戴口罩 | -10分 | 基本防護要求 |

### **3. 績效應用機制**

**加盟店續約考量：**
- 90+ 分：優先續約，優惠條件
- 80-89 分：正常續約
- 70-79 分：輔導續約，改善計劃
- <70 分：審慎評估，可能終止

**直營店店長考績：**
- 95+ 分：年終獎金+20%，升遷優先
- 85-94 分：年終獎金+10%
- 75-84 分：標準獎金
- <65 分：考慮調職

## 🔄 **工作流程**

### **季度計劃 (系統自動)**
```
每季初 → 自動生成巡店計劃 → 分配給圓圓等巡店人員 → 開始提醒機制
```

### **巡店執行流程**
```
系統提醒 → 現場巡店 → 填寫67項檢核 → 自動計算得分 → 
通知店長 → 標記改善項目 → 5天內上傳照片 → 審核通過 → 結案
```

### **改善追蹤**
- **D+0**: 巡店完成，通知店長需改善項目
- **D+3**: 自動提醒上傳改善照片
- **D+5**: 改善截止，逾期自動警報  
- **D+7**: 升級通知總公司主管

## ⚠️ **重要特色**

### **1. 重複違規加重機制**
- 同項目2次違規：扣分 × 1.5
- 同項目3次以上：扣分 × 2
- 跨季度重複：額外扣5分

### **2. 一票否決項目**
以下項目直接降為**D級**：
- 滅火器過期/缺失
- 員工健康檢查過期>30天
- 潔面刷嚴重發霉
- 專用針管交叉使用
- 妨礙公衛行為確認

### **3. 照片改善驗收**
- 清晰度：能清楚看到改善內容
- 角度：與原問題相同角度
- 完整性：完整展示改善區域
- 審核：通過/部分通過/不通過
