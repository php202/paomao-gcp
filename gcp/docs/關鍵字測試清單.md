# LINE 關鍵字測試清單

依此清單在 LINE 傳送關鍵字，可驗證 GCP 各功能是否正常。  
**員工端**用「泡泡貓 專屬內部員工」；**店家端**用「PAOPAO」各店。

---

## 一、員工 LINE（/line-webhook）

### 權限前（不需開通即可測）

| 關鍵字 | 預期行為 |
|--------|----------|
| **我要註冊** | 回「您已是正式員工…」或格式說明；若附「姓名：王小明」等會寫入請求員工ID |
| **我要打卡** | 回打卡按鈕（傳送位置 / 點擊開啟打卡） |

### 需已開通

| 關鍵字 | 預期行為 |
|--------|----------|
| **最新活動** | 回活動連結 |
| **特約商店** | 回線上課程連結 |
| **我要開店** | 回「請傳送店面位置」+ 位置按鈕 |
| **明日預約** | 回「此功能暫時關閉，敬請見諒。」 |
| **補打卡** | 回填寫範本（店家、補登時間、輸入上/下班） |
| **補打卡申請**<br>店家：竹北光明<br>補登時間：2025/02/16 09:00<br>輸入上/下班：上班打卡 | 寫入員工打卡紀錄並回「補打卡成功」 |
| **Line問題集** | 回待處理問題清單（需 LINE_HQ_SS_ID） |
| **店家回覆狀態** | 僅管理者：回直營店未回覆數與完成率 |
| **查詢打卡記錄** | 回 Quick Reply（本月/上月/店家今天…） |
| **本月出勤** | 回本月出勤紀錄 |
| **上月出勤** | 回上月出勤紀錄 |
| **店家今天出勤** | 回今日各店出勤（有上班/沒上班/尚未註冊） |
| **店家本月出勤** | 管理者：各店本月出勤 |
| **店家上月出勤** | 管理者：各店上月出勤 |
| **店家可預約時間** | 管理者：各店可預約時段 |
| **明天預約清單** 或 **明日預約清單** | 回明日預約列表 + Quick Reply「了解 09xx」 |
| **我要了解客人 0925810424** | 回該客人 AI 分析結果（需 Core API） |
| **上月小費** | 回報表連結（需 Core API） |
| **神美日報** | 回「開啟日報」按鈕（需 Core API） |

### 工作流程（依試算表）

若已設定 `WORKFLOW_SHEET_SS_ID` 且試算表「公司流程」A 欄有關鍵字、B 欄為連結，傳送該關鍵字會回「請點擊: {連結}」。  
（關鍵字由試算表內容決定，無固定清單。）

## 二、店家 LINE / PAOPAO（/store-line-webhook）

| 關鍵字 | 預期行為 |
|--------|----------|
| **我的會員** | 不傳訊、不寫挽留、不寫訊息一覽 |
| **課程介紹** | 不傳訊、不寫挽留、不寫訊息一覽 |
| **送出預約** | 不傳訊、不寫挽留、不寫訊息一覽 |
| **線上預約** | **會回傳**：查空位 + 模板文案（近期空位 + 鼓勵預約） |
| **您已取消預約** | 不傳訊、不寫挽留、不寫訊息一覽 |
| 其他任意文字 | 寫入「訊息一覽」試算表（時間、userId、店名、姓名、訊息…） |

---

## 三、比對用（完全匹配）

以下需**完全一致**才會觸發：

- `我要打卡`（不是「我要打卡嗎」）
- `最新活動`、`特約商店`、`我要開店`
- `明日預約`（四字才會回「此功能暫時關閉」）
- `明天預約清單` 或 `明日預約清單`
- `神美日報`
- `查詢打卡記錄`、`本月出勤`、`上月出勤`
- `店家今天出勤`、`店家本月出勤`、`店家上月出勤`、`店家可預約時間`

其餘多為「包含」即觸發（例如訊息中含 `補打卡`、`我要註冊`、`店家回覆狀態`、`上月小費`、`我要了解客人`、`Line問題集`）。

---

## 四、建議測試順序

1. **我要註冊**（權限前）→ 再 **我要打卡**（權限前）。
2. **補打卡** → 應收到範本；再貼一次「補打卡申請 + 店家 + 補登時間 + 輸入上/下班」→ 應寫入並回成功。
3. **明天預約清單** → 應有列表 + 下方 Quick Reply「了解 09xx」。
4. **店家今天出勤**（管理者）→ 應有今日出勤。
5. 店家帳號打 **線上預約** → 應收到空位文案；打 **我的會員** → 無回覆。
