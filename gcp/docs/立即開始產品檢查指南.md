## 🔍 **檢查技巧**

### **高效對比方法**
1. **分割畫面**: 兩個瀏覽器視窗並排
2. **搜尋定位**: 用產品名稱快速找到對應項目
3. **截圖記錄**: 發現問題時立即截圖
4. **即時記錄**: 在檢查工具中記錄發現的問題

### **常見問題識別**
- 🔄 **圖片錯配**: A產品用了B產品的圖片
- 🖼️ **圖片缺失**: 某一邊系統沒有圖片
- 📝 **品名差異**: 名稱格式不一致
- 🎨 **圖片品質**: 解析度或清晰度問題
