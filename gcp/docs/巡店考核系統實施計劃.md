# 泡泡貓巡店考核系統實施計劃

## 🎯 **系統目標**

### **主要功能**
1. **季度巡店追蹤** - 確保每間店一季巡一次
2. **智能提醒系統** - 自動提醒該巡店的門市
3. **標準化考核** - 統一的評分標準和流程
4. **改善追蹤** - 5天內照片回傳機制
5. **績效考核** - 整合店長考績和加盟續約

---

## 📊 **系統架構**

### **數據庫設計**
- `inspection_categories` - 檢核分類
- `inspection_items` - 具體檢核項目  
- `inspection_schedules` - 巡店計劃
- `inspection_records` - 巡店記錄
- `inspection_details` - 檢核明細
- `improvement_photos` - 改善照片
- `inspection_notifications` - 通知記錄

### **評分系統**
- **滿分 100 分，扣分制**
- **6大類別：法規遵循、衛生管理、設備維護、環境清潔、服務區域、員工規範**
- **67個標準檢核項目**
- **A+/A/B/C/D 五級評等**

## 🔄 **工作流程**

### **1. 季度計劃制定 (每季初)**
1. 系統自動生成下季巡店計劃
2. 總公司分配巡店人員和時間
3. 系統開始每日提醒機制

### **2. 巡店執行流程**
```
準備巡店 → 現場檢核 → 填寫記錄 → 計算得分 → 
通知店長 → 改善項目 → 照片回傳 → 審核通過 → 結案
```

### **3. 改善追蹤機制**
- **D+0**: 巡店完成，系統通知店長改善項目
- **D+3**: 自動提醒上傳改善照片  
- **D+5**: 改善截止日，逾期自動警報
- **D+7**: 升級通知總公司主管
