# 映像已推送完成，接下來要做的事

## 1. 試算表共用給 Cloud Run 的服務帳戶（必做）

查服務帳戶 email：

```bash
source set-env.sh
gcloud iam service-accounts list
```

預設通常是：`專案編號-compute@developer.gserviceaccount.com`

到**每個用到的 Google 試算表**（員工清單、店家、Token、產出）→ **共用** → 新增上述服務帳戶 → **編輯者**（產出那張要能寫入）。

---

## 2. 建立兩個 Cloud Run Job

在 `gcp` 目錄下執行（先設定好環境變數再跑）：

```bash
source set-env.sh
./create-jobs.sh
```

若還沒設定 Secret Manager，腳本會用環境變數。請先把需要的變數加進 `set-env.sh` 或先 `export` 再執行（見下方變數說明）。

---

## 3. （選用）Secret Manager 放 Token、Gmail 密碼

```bash
echo -n "你的SayDou_Bearer_Token" | gcloud secrets create saydou-token --data-file=-
echo -n "paopaomao.of@gmail.com" | gcloud secrets create gmail-user --data-file=-
echo -n "你的Gmail應用程式密碼" | gcloud secrets create gmail-app-password --data-file=-
```

授權給 Cloud Run 用：

```bash
source set-env.sh
export PROJECT_NUMBER=$(gcloud projects describe $PROJECT_ID --format='value(projectNumber)')
for s in saydou-token gmail-user gmail-app-password; do
  gcloud secrets add-iam-policy-binding $s \
    --member="serviceAccount:${PROJECT_NUMBER}-compute@developer.gserviceaccount.com" \
    --role="roles/secretmanager.secretAccessor"
done
```

若已建好 Secret，可改 `create-jobs.sh` 用 `--set-secrets`（參考 DEPLOY.md 作法 A）。

---

## 4. 排程：Cloud Scheduler

- **方式一**：在 [Cloud Run Console](https://console.cloud.google.com/run) → **Jobs** → 選 Job → **排程** 用介面設定（最直觀）。
- **方式二**：用指令建立，見 DEPLOY.md 第六節。

---

## 5. 之後程式有改

只要再執行一次建映像即可：

```bash
./build.sh
```

Job 會自動用新的 `pao-run:latest` 映像。

---

**環境變數整理**（給 Job 用，可加在 `set-env.sh` 或執行前 export）：

| 變數 | 用途 |
|------|------|
| `ADMIN_EMAIL` | Token 異常時收信 |
| `GMAIL_USER` | 寄信用 Gmail |
| `GMAIL_APP_PASSWORD` | Gmail 應用程式密碼（建議放 Secret） |
| `SAYDOU_BEARER_TOKEN` 或 `TOKEN_SHEET_SS_ID` | SayDou / 從試算表讀 Token |
| `LINE_STAFF_SS_ID`, `LINE_STORE_SS_ID`, `OUTPUT_SS_ID` | 月報用試算表 ID |
